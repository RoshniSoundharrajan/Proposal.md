# Title
Rosie's Bakery

## Repository
https://github.com/RoshniSoundharrajan/Proposal.md.git

## Description
1-2 sentence description of what it will do and how it relevant to media and digital arts.

This program will be a interactive game where customers will come into your bakery and you have to bake something depending on their order. It will display art of the ingredients you use and will output the art of the baked pastry you've made. 


## Features
- Feature 1: Taking customer orders
	- You will input questions for the program, asking what the customer wants to order, how much of that product they want, and if they wanted to add on a different item. The customer will pick randomly from a list of the baked goods available.
   
- Feature 2: Picking the ingredients
	- You will ask the program to display an image of the ingredients available in the pantry. You will input a list of ingredients you will use, and the program will update how much of each ingredient is used up.
   
- Feature 3: Baking the goods
	- The program will keep asking you what the next step of the recipe is, and you will keep inputting what ingredient to use in each step. The program is will stop asking for the next step once you input that the recipe is done. The user inputs will be stored. The program will then output art of the baked good that is defined to have those same user inputs. 

## Challenges
- I'll need to figure out how I can upload art or create the art in the program
- I'll need to figure out how to update the amount of each ingredient separately in the list 
- I'll need to figure out how the program will use the recipe steps that the user inputs to compare with define functions of the baked goods. 

## Outcomes
Ideal Outcome:
- I hope for the project to be able to accomplish most of the features. I also hope for the program to not run into too many issues of updating the inventory of ingredients or saving information of the user inputs of the recipes. 

Minimal Viable Outcome:
- I hope for the program to at least be able to output art of the ingredients that you plan to use. 

## Milestones

- Week 1
  1. Create user inputs to take customer orders
  2. Create a list of the menu and ingredients
  3. Define recipe for each item on list

- Week 2
  1. Update the inventory of ingredients every time they are used
  2. Create user inputs to follow a recipe and store them

- Week N (Final)
  1. Compare user inputs to defined recipes to output baked good
  2. Create the art of the ingredients and baked goods that will output
